🌐 UDN 新聞輿情分析平台

本專案為以 Django 架構打造的新聞分析網站，主要針對 2025 年上半年的聯合新聞網（UDN）資料進行蒐集與分析。 透過自動化爬蟲擷取每日新聞資料，結合自然語言處理與資料科學技術，進行一系列深入的文本分析， 包括：斷詞處理、關鍵詞統計、熱門人物萃取、情緒分類、 關鍵詞關聯探勘，以及整合語言模型實現的 自動摘要報告生成。

除了提供 即時互動式的可視化圖表，本平台亦設計多個模組功能，供使用者查詢特定詞彙趨勢、觀察人物聲量變化， 並針對 特定主題（如：關稅） 進行情境式分析。此外，新增的「各國關注度與情緒導向分析」功能， 能呈現不同國家在報導中的被關注程度與輿情傾向，協助觀察媒體對全球事件的態度與情緒。

本系統整合多項現代技術，包括 Django 框架、Bootstrap 前端、Selenium 自動化爬蟲、CKIP NER 實體辨識、 Chart.js 與 WordCloud.js 視覺化技術，以及 Gemini / OpenAI 語言模型 API 應用， 建構出一個功能豐富、操作直覺、具可擴展性的輿情分析平台。

🔗 GitHub Repo： udn_site_news_analysis_django

📌 分析功能總覽
  • 熱門關鍵詞分析：統計各類新聞中的高頻詞彙。
  • 熱門人物辨識：透過 CKIP NER 技術擷取重要人物。
  • 關鍵詞熱門度分析：查詢任意關鍵詞在各類新聞中的篇數與頻率。
  • 關鍵詞關聯分析：觀察兩組關鍵詞同現的新聞與段落。
  • 關稅主題分析：提供關稅新聞篇數與詞頻之時間趨勢圖。
  • 情緒分析：針對自訂關鍵詞新聞內容進行情感極性分類。
  • 國家領袖聲量觀測：觀察川普、習近平、普亭等人物聲量變化。
  • 語言模型報告生成：呼叫 Gemini / OpenAI 生成摘要報告。
  • 各國的關注程度與情緒導向：2025年上半年聯合新聞網對各國的關注程度與情緒導向。
  • 熱門人物排行(資料庫)：從資料庫即時查詢熱門人物排名。
  • 熱門人物立刻計算：管理者定時執行熱門人物計算任務。
  • 自訂全文檢索與關聯分析(db)：基於資料庫的全文關鍵詞關聯分析。
  • 川普聲量我最大：專門針對川普新聞聲量的觀測與分析。
📂 功能模組與資料路徑簡介
  • app_top_keyword/：熱門關鍵詞分析
  • app_top_person/：熱門人物排行分析
  • app_user_keyword/：自訂關鍵詞熱門度分析
  • app_user_keyword_association/：自訂全文檢索與關聯分析
  • app_user_keyword_sentiment/：自訂關鍵詞情緒分析
  • app_tariff/：關稅新聞分析與報導
  • app_presidents/：國家領袖聲量追蹤
  • app_user_keyword_llm_report/：自訂關鍵詞語言模型分析報告
  • app_feature_db/：各國關注程度與情緒導向分析
  • app_top_person_db/：熱門人物排行（資料庫查詢）
  • app_top_person_db:calculate_top_person：熱門人物立刻計算（管理者定時執行）
  • app_user_keyword_db/：自訂全文檢索與關聯分析（資料庫版）
  • app_trump/：川普聲量專屬分析
🔧 技術架構
  • Django 架構 + Bootstrap 前端設計
  • 資料儲存格式：CSV 檔案 / Django ORM
  • 爬蟲技術：Selenium + BeautifulSoup
  • 可視化：Chart.js / WordCloud.js
  • 語言模型應用：OpenAI、Gemini、Ollama
